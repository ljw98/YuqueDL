## 安全结论（当前）

| 维度 | 判断 |
|------|------|
| 路径穿越 | **已防护**（`assertBookName` + `resolveSafe` 实测 400） |
| Open/MCP 鉴权 | **已防护**（无 Bearer → 401） |
| CSRF（浏览器写请求） | **已防护**（跨站 Origin → 403） |
| Token 落盘 / 展示 | **加密 + mask**（settings 返回 mask；publicTask 掩码） |
| Markdown XSS | **html:false + 轻量 sanitizer**；`v-html` 仅库内预览路径 |
| 导出 DoS | **限流 3/min + 全局互斥 1**；系统 `zip` / Node 流式回退 |
| 建任务 / Token 检测 | **有限流** |
| 登录限流 | **10/min**；默认不信任 XFF |
| 阻断级 RCE | **未发现**（`zip` 仅固定参数 + `cwd=bookRoot`） |

### 仍属产品设定 / 已知边界（不当漏洞硬改）

- 登录保护可关闭 → 局域网控制台开放（用户预期）
- 开发模式下 h3 错误响应仍可能带 stack（仅 dev）
- 单实例内存队列；多进程共享 `data/` 需严格锁或拆数据目录
- `scryptSync` 同步调用，高并发暴力撞库时可能阻塞事件循环（有登录限流兜底）
