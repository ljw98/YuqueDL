## 优化建议列表（未自动大改，供选型）

### P1 体验 / 稳定

1. **任务来源关联**：任务记录 `source: manual|schedule` + `scheduleId`，详情可跳回规则  
2. **定时全局预算**：每日最大触发次数 / 全局冷却，防 Token 失效时刷失败  
3. **jobs.json 膨胀**：日志截断策略可视化；成功任务自动归档或保留 N 天  
4. **知识库体积统计**：列表显示占用空间，一键清理媒体缓存目录  

### P2 工程

5. 前后端类型单一来源（去掉 `store`/`types/api` 双份漂移风险）  
6. 前端减少 `any`（schedules 行类型）  
7. Playwright 最小 E2E：登录开关、建任务、导出  
8. CI：`pnpm test` + `web test:unit` + lint  

### P3 可选

9. 导出进度（大库 zip 百分比）  
10. 库内全文搜索  
11. MCP 补 `yuque_export_book` 工具  
12. 反代示例（Caddy/Nginx）片段  

## 明确不做（产品）

- 强制登录 / 公网鉴权模型  
- 密码复杂度强制  
- 把「局域网可匿名」当漏洞
